# 🔌 Electrical Wiring Diagram & Pinout Mapping

This document details the pinout connections, power supply architecture, and wiring diagrams for the ESP32 smart bilge drainage system.

---

## 📌 Microcontroller Pinout Mapping (ESP32)

| Peripheral Device | Pin Name | ESP32 GPIO Pin | Signal Type | Notes |
| :--- | :--- | :--- | :--- | :--- |
| **HC-SR04 Sensor** | VCC | 5V / VIN | Power | Requires stable $5\text{V}$ DC supply |
| **HC-SR04 Sensor** | GND | GND | Ground | Common system ground |
| **HC-SR04 Sensor** | Trigger | **GPIO 5** | Digital Output | $10\,\mu\text{s}$ trigger pulse |
| **HC-SR04 Sensor** | Echo | **GPIO 18** | Digital Input | ToF echo measurement ($3.3\text{V}$ logic compatible) |
| **Relay Module** | VCC | 5V / VIN | Power | Relay coil power |
| **Relay Module** | GND | GND | Ground | Common ground |
| **Relay Module** | IN (Input) | **GPIO 4** | Digital Output | *Active LOW* (`LOW` = Pump ON, `HIGH` = Pump OFF) |
| **Float Switch** | Terminal 1 | **GPIO 19** | Digital Input | Configured with internal `INPUT_PULLUP` |
| **Float Switch** | Terminal 2 | GND | Ground | Closes to GND when submerged (Emergency Override) |
| **Seaflo 500 GPH Pump**| Positive (+) | Relay (COM - NO)| 12V Power | Switched via Normally Open (NO) relay contact |
| **Seaflo 500 GPH Pump**| Negative (-) | Battery (-) GND | 12V Ground | Direct connection to 12V battery ground |

## ⚡ Electrical Safety & Isolation
1. **Optocoupler Protection:** The relay module features optocoupler isolation to protect ESP32 GPIO pins from inductive voltage spikes generated by the pump motor.
2. **Common Grounding:** Ground potential must be shared between the $5\text{V}$ control logic and $12\text{V}$ power circuits.
3. **Fail-Safe Operation:** In the event of a microcontroller power loss or firmware crash, the mechanical float switch provides direct hardware override capability.
